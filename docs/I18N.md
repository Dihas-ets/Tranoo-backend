# Internationalisation Tranoo

## Langues supportées

**fr** (défaut), **en**, **ar** — alignées avec les apps Flutter.

## Web (`tranoo_landing`)

- **Bibliothèque** : [next-intl](https://next-intl-docs.vercel.app/)
- **Fichiers** : `messages/fr.json`, `messages/en.json`, `messages/ar.json`
- **Config** : `i18n/routing.ts`, `i18n/request.ts`, `middleware.ts`
- **Sélecteur de langue** : `components/LocaleSwitcher.tsx` (login + sidebar)
- **Cookie** : `NEXT_LOCALE` (pas de préfixe `/fr/` dans l’URL)

### Pages migrées (phase 1)

- `/login`
- Section demandes de vérification transitaire + page détail
- Erreurs API mappées via `lib/i18n-helpers.ts`

### Ajouter une traduction

1. Ajouter la clé dans `messages/fr.json`, `en.json`, `ar.json`
2. Dans un composant client : `const t = useTranslations("verification");` puis `t("maCle")`

## Backend (Express)

- **Codes stables** : `src/utils/errorCodes.js`
- **Messages localisés** : `src/utils/apiResponse.js` (`LOCALIZED_MESSAGES`)
- **Locale** : header `Accept-Language` (envoyé par le web via axios)
- **Contrôleur migré** : `transitaireVerificationController.js`, CAPTCHA middleware

Réponse type :

```json
{
  "success": false,
  "code": "TRANSITAIRE_VERIF_PENDING",
  "message": "Une demande est déjà en cours d'examen..."
}
```

## Flutter (`tranoo` + `tranoo_pro`)

- **Fichiers** : `lib/l10n/app_{fr,en,ar}.arb`
- **Mapping API** : `lib/utils/api_error_message.dart` (codes → `AppLocalizations`)
- Régénérer après modification ARB : `flutter gen-l10n`

### Nouveaux codes API (exemples)

| Code | Usage |
|------|--------|
| `CAPTCHA_INVALID` | Turnstile échoué |
| `TRANSITAIRE_VERIF_PENDING` | Demande déjà en cours |
| `TRANSITAIRE_VERIF_SUBMIT_SUCCESS` | Envoi dossier OK |
